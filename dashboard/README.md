# Power BI dashboard

Four report pages are provided as individual PNG previews in `screenshots/` and as a single PDF export (`RidgeLine_Analytics_Dashboard.pdf`). The editable report is in `../powerbi/RidgeLine_Analytics_Dashboard.pbix`.

The PNG/PDF exports are static previews. Interactive filters and drill-down require Power BI Desktop and the PBIX file. Live connection/refresh behavior has not been independently tested in this package.
